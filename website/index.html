A look around

Browse — a thumbnail grid with a folder tree, index overlays and instant sorting.

Built for folders full of photos

Pixee opens a directory of images and gets out of the way. Thumbnails are decoded on four background threads into a local SQLite cache and prioritised by what's actually on screen, so the grid fills from the top-left down instead of making you wait for the whole folder.

It exists because the alternatives crawl on a network share. Every directory read, image decode and file operation happens off the UI thread, and Pixee deliberately avoids Qt's stock file models and dialogs — the ones that stall for seconds on an SMB mount. The window stays responsive whether the photos are on an SSD or a NAS across the hall.

What's in it

  • Thumbnails that keep up

    A four-worker decode pool feeding a SQLite cache, ordered by distance from the viewport, with the rest of the folder filling in behind you.

  • A real viewer

    Fit, 1:1 and stepped zoom from 0.1× to 8×, space-drag panning, fullscreen, and a five-image preload so prev/next is instant.

  • Edit without leaving

    Rotate, flip and crop with a marching-ants marquee and optional fixed ratio. Brightness, contrast, saturation, hue and gamma preview live, then apply at full resolution on save.

  • File operations that explain themselves

    Copy, move, rename, delete and batch rename through a proper task queue. Clashes show both files side by side — thumbnail, size, date — so you choose by eye.

  • Every format your Qt build can read

    JPEG, PNG, WebP, GIF, BMP, TIFF and ICO out of the box; HEIC, AVIF, PSD and XCF come bundled in the Windows builds.

  • Yours to change

    MIT licensed, themeable with plain Qt stylesheets, and translated into English and Hungarian with more scaffolded.
